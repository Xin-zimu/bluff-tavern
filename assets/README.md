# 美术资源目录

此目录遵循 `ART_ASSETS_PLAN.md`，当前 V0.1 不包含任何原游戏版权素材，也不下载第三方素材。网页现阶段使用原创 CSS 几何图形、色板与文字占位。

- `backgrounds/`：BG-01、BG-02、BG-03
- `textures/`：TEX-01、TEX-02
- `cards/`：CARD-01～CARD-05
- `characters/<character>/`：八名原创角色的表情集
- `props/`、`items/`、`emotes/`、`ui/`、`effects/`、`icons/`
- `source/`：可编辑源文件；`licenses/`：来源与许可证记录

正式导出文件使用小写 snake_case；背景优先 WebP，透明角色使用 WebP lossless/PNG，小图标优先 SVG/WebP。
