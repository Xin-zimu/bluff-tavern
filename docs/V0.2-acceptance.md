# V0.2 验收报告

日期：2026-08-17
版本：0.2.0
状态：通过

## 实现范围

- 创建/房间码加入/昵称/实时玩家列表。
- 房主识别与离开后的自动转移。
- 玩家准备和取消准备。
- 房主可配置 2–8 人最大人数；缩小到低于当前人数会被服务器拒绝；配置变更会取消准备。
- 房主可移出其他玩家；被移除玩家收到专用通知且不再拥有 Socket 房间成员资格。
- 服务端对房主、房间状态与 UUID requestId 的最终裁决。
