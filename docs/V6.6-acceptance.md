# V6.6 Acceptance

V6.6 is the final V6 stabilization target. It keeps the core rules scoped to Classic and Quick, and focuses on lifecycle completeness, readable table state, reconnect recovery, mobile usability, and production stability.

## Required Checks

- Create a 2-player room, ready both players, start a Classic game, and confirm the round target appears as a central card before docking to the HUD.
- Confirm the table HUD always shows the target card, round number, public pile, last declaration, current status, and active player focus.
- Play 1 to 3 cards, challenge the previous play, and confirm `CHALLENGE_CALLOUT`, `REVEAL`, `VERDICT`, `PUNISHMENT_INTRO`, `PUNISHMENT_TRIGGER`, and `PUNISHMENT_RESULT` occur in order.
- Confirm revealed cards show the real card faces and Joker counts as honest.
- Confirm verdict text appears only after every challenged card has flipped and held for about one second.
- Confirm all gameplay buttons are unavailable outside `TURN`.
- Finish a match and confirm the result screen offers return to room, room exit, and host replay flow through the room lobby.
- Return to room after game over and confirm readiness resets before the next match starts.
- Open the rules panel during a match and confirm it fits desktop and mobile viewports.
- Confirm the first-time contextual tip can be dismissed.
- Disconnect or refresh a player during a game and confirm the room shows an offline/reconnect state without losing the authoritative snapshot.
- Confirm an active-game explicit leave keeps the player seat disconnected instead of corrupting room/game state.
- Confirm the Error Boundary offers reconnect and return-to-lobby recovery actions.

## Mobile Checks

- 360 x 800 portrait.
- 390 x 844 portrait.
- 412 x 915 portrait.
- Landscape phone viewport.
- Confirm hand cards, action buttons, round target HUD, rules panel, reveal cards, and result actions do not overflow horizontally.

## Regression Checks

- `pnpm typecheck`
- `pnpm test`
- `pnpm build`

## Release Checks

- `/health` returns `version: "6.6.0"` and runtime counters for rooms, players, connections, and matches.
- `apps/web/public/sw.js` uses a V6.6 cache key so old clients refresh assets.
- No V7 items, skills, random events, economy, ranking, or public matchmaking are enabled.

## Known Boundaries

- `game:restart` remains as a compatibility event, but the primary V6.6 replay path is `game:returnToRoom` followed by ready/start from the room lobby.
- Item usage remains disabled and returns `FEATURE_DISABLED`.
