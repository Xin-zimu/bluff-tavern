# V2.5 验收报告

日期：2026-08-17

## 范围

- 支持 7–8 人开局，使用 40 张动态牌堆与两发实弹轮盘配置。
- 八人桌以相对座位排序，本地玩家保持底部中央；桌面空间不足时自动降级为触控友好单列。
- 每个客户端只接收自己的真实手牌；断线后 session token 恢复原座位及私有游戏视图。
