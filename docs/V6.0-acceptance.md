# V6.0 Acceptance

V6.0 is accepted only when the authoritative gameplay loop works from start to final winner across 2 to 8 players.

## Required Checks

- Classic and Quick are the only enabled modes.
- Every alive player receives exactly 5 cards at each round start.
- Eliminated players receive 0 cards and never receive a turn.
- Playing 1 to 3 cards is accepted during a normal `TURN`.
- Invalid card selections are rejected.
- A player who empties their hand forces the next alive player to challenge.
- Forced-challenge timeout auto-challenges.
- Normal timeout auto-plays one legal card.
- Challenge, reveal, verdict, punishment intro, trigger, result, round end, and game over are separate phases.
- `phaseSequence` increases on every phase transition.
- `game:snapshot` includes server timing fields.
- `hit` is not public before `PUNISHMENT_RESULT`.
- Each player has an independent 6-chamber revolver.
- A sixth unresolved shot for a player is guaranteed to hit.
- A 3-player game can eliminate one player and continue as a 2-player game with 5 cards each.
- Reconnect sends the current authoritative snapshot.
- Multiplayer clients observe the same `phaseSequence`.
- Animations are client-rendered and never drive server phase transitions.

## Verification Commands

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

All commands must pass before deployment.
