# V6.3 Acceptance

V6.3 does not change gameplay rules. It validates the cinematic layer, audio controls, reduced-motion behavior, and end-of-round presentation.

## Required Checks

- Start a 2-player Classic room, ready both players, and start the game.
- Play one card, challenge it, and observe the full sequence from `CHALLENGE_CALLOUT` through `ROUND_END`.
- Confirm `REVEAL` flips each revealed card in order and highlights honest cards differently from bluff cards.
- Confirm `VERDICT` uses red impact styling for a bluff and gold freeze styling for a failed challenge.
- Confirm `PUNISHMENT_INTRO`, `PUNISHMENT_TRIGGER`, and `PUNISHMENT_RESULT` still show the generated revolver asset.
- Confirm a hit shows recoil, muzzle flash, table shake, and non-gory elimination feedback.
- Confirm a dry fire shows a smaller smoke result without full hit flash.
- Confirm eliminated seats dim and show the eliminated portrait frame.
- Finish a match and confirm the victory panel shows winner, player count, duration, challenge counts, and elimination order.
- Toggle sound off, then trigger another phase and confirm game phase sounds stop.
- Toggle low-power mode and confirm high-cost stage animations are disabled.
- Toggle reduced animation mode and confirm the game remains readable without motion.

## Mobile Checks

- Run the same flow in a narrow viewport.
- Confirm the cinematic panel, reveal cards, revolver stage, settings buttons, and victory stats fit without horizontal overflow.
- Rotate to landscape and confirm the table remains usable.

## Regression Checks

- `pnpm install --frozen-lockfile`
- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`

## Release Check

- `/health` returns `version: "6.3.0"`.
- `apps/web/public/sw.js` uses a V6.3 cache key so clients refresh old assets.
