# V1.0 验收报告

日期：2026-08-17  
状态：通过

## 范围

- 2–4 人可完成创建房间、加入、准备、开局、出牌、质疑、轮盘惩罚、淘汰、胜利和再来一局。
- 游戏/结算阶段断线后保留座位，浏览器会话用私有 token 恢复相同玩家身份和服务端游戏快照。
- 手机竖屏提示横屏，横屏布局保留可触控大按钮；基础进入与选牌动画及 Web Audio 合成提示音已启用，遵守 reduced-motion 偏好。
- 提供 Nginx、systemd 和构建脚本模板；所有视觉与音效均为原创 CSS/浏览器生成占位，不含原游戏资产。

## 验证

- `pnpm lint`：通过。
- `pnpm typecheck`：通过。
- `pnpm test`：16 项测试通过，覆盖协议、房间状态、服务端牌局、四个真实 Socket.IO 客户端和真实断线恢复集成状态。
- `pnpm build`：通过。
- `pnpm --filter @bluff-tavern/server exec tsx scripts/live-reconnect-v1.0.ts`：通过 Vite `/socket.io/` 反代启动两名真实客户端、开局、断开一名客户端并以 token 恢复原座位。

## 已知边界

- 房间和牌局仍为单进程内存状态，服务重启会清空；无断线宽限倒计时、PWA、后台恢复或多实例支持。这些属于 V1.5 及之后的明确范围。
