# V1.5 验收报告

日期：2026-08-17  
状态：通过

## 范围

- 手机竖屏会提示横屏；横屏可完整游玩，已保留安全区间距与 50px 以上的大型主要操作目标。
- 牌桌支持标准 Fullscreen API；卡牌触控禁用双击/高亮等多余浏览器手势，并保持最多三张的服务端权威出牌限制。
- PWA manifest、standalone 配置、原创应用图标及同源 Service Worker 已随生产构建发布；不缓存 Socket.IO 请求。
- Socket 自动退避重连；连接、设备重新联网和页面回到前台时均会恢复私有 session，服务端继续提供原座位和私有手牌视图。
- 在线状态与服务端连接状态分离显示；低性能设备及 `prefers-reduced-motion` 会关闭非必要动画。

## 验证

- `pnpm lint`、`pnpm typecheck`：通过。
- `pnpm test`：17 项通过，包含真实 Socket.IO 多人/重连测试及 PWA manifest、图标和缓存 Worker 测试。
- `pnpm build`：通过。
- 开发服务器实测：`GET /manifest.webmanifest` 返回 standalone manifest，`HEAD /sw.js` 返回 `200 OK`。
- `pnpm --filter @bluff-tavern/server exec tsx scripts/live-reconnect-v1.0.ts`：通过 Vite `/socket.io/` 反代验证真实断开及恢复。

## 已知边界

- iPhone 的“添加到主屏幕”需由 Safari 分享菜单手动发起；浏览器安全策略不允许网页强制安装或全屏。
- PWA 缓存仅提供应用壳和已访问同源资源，不尝试离线运行多人牌局；断线宽限倒计时和持久化仍不在本版本范围。
