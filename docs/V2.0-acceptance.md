# V2.0 验收报告

日期：2026-08-17  
状态：通过

## 范围

- 支持 2–6 人：2–4 人使用 20 张牌，5–6 人使用 30 张牌；所有数量在共享配置中定义。
- 5–6 人游戏每把左轮包含两发实弹；淘汰、跳过与胜负仍由服务器权威状态机判断。
- 房主可选经典 15 秒或快速 7 秒模式；回合超时由服务器自动随机选择一张当前手牌并统一广播。
- 牌桌在 5–6 人时使用三列布局，窄屏保留单列可触控布局。

## 验证

- `pnpm lint`、`pnpm typecheck`：通过。
- `pnpm test`：23 项通过，覆盖 2/3/4/5/6 人牌堆、六位真实 Socket.IO 客户端、快速模式状态和既有牌局/重连回归。
- `pnpm build`：通过。

## 已知边界

- 7–8 人、动态缩放和八客户端压力测试严格留给 V2.5；V2.0 不引入 Party 事件、角色或道具。
