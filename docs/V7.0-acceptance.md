# V7.0 Acceptance

V7.0 is accepted when extension gameplay can be enabled from the room lobby without changing the default V6 classic experience. All V7 systems are server-authoritative, testable, and disabled by default.

## Scope

- Extension toggles: items, tavern events, and character abilities.
- Items: spyglass, pocket watch, and tavern mug only.
- Tavern events: rapid night, candle flicker, and double danger only.
- Character abilities: one lightweight passive ability per character.

## Explicitly Out Of Scope

- Shop, currency, ranking, public matchmaking, friends, and complex social systems.
- Active ability buttons or response windows.
- Swapping another player's cards, viewing another player's hidden hand, changing punishment hits, or adding bullets.
- New game modes beyond Classic and Quick.

## Acceptance Checks

- New rooms start with every `settings.v7` flag set to `false`.
- Changing any V7 flag in the lobby clears ready state through the existing room settings path.
- With every V7 flag disabled, the V6 match loop still deals, turns, challenges, reveals, punishes, eliminates, and returns to room normally.
- `itemsEnabled=false` deals no item and rejects `game:useItem`.
- `itemsEnabled=true` deals only spyglass, pocket watch, and tavern mug.
- Item inventories and item effects are private to the current viewer snapshot.
- `tavernEventsEnabled=false` keeps `GameSnapshot.tavernEvent` null.
- `tavernEventsEnabled=true` can draw public events at round start; rapid night only changes round turn time, while candle flicker and double danger only change presentation pressure.
- `characterAbilitiesEnabled=false` keeps `GameSnapshot.abilityEffect` null.
- `characterAbilitiesEnabled=true` freezes lobby character choices at match start and sends ability effects only to the affected viewer.
- Every first-batch character ability is covered by unit tests.

## Verification

Run before release:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

The real Socket.IO test suite must include at least one item flow and one character ability flow.
