# V3.0 验收报告

日期：2026-08-17  
状态：通过

## 范围

- Party/Custom 规则由房主在大厅配置，开局后服务端冻结；牌局中无法由客户端改写。
- Party 每轮服务端生成可复现的醉酒洗牌、快速夜或双倍危机，并向所有客户端广播公开事件状态。
- Custom 支持 5–30 秒回合、事件开关和 1–5 发实弹；所有裁决仍保留服务端权威。
