# 《诡牌酒馆 / Bluff Tavern》完整美术素材生成清单与精确提示词

> 用途：直接交给 Midjourney、Stable Diffusion、Flux、GPT Image、通义万相、即梦等生图模型批量生成。  
> 项目类型：手机浏览器优先的 2–8 人多人诈唬派对游戏。  
> 核心场景：昏暗、温暖、略危险的旧式酒馆，玩家围坐木桌，通过出牌、诈唬、质疑和轮盘惩罚进行对局。  
> 原创要求：不得直接复制《Liar's Bar / 骗子酒馆》的具体角色、构图、Logo、UI、武器模型、卡牌设计或其他受版权保护的视觉资产。  
> 输出要求：所有素材必须具有统一世界观、统一材质、统一光照和统一线条语言。

---

# 1. 全局统一美术风格

所有素材都必须尽量保持以下视觉规则。

## 1.1 世界观

关键词：

```text
dark whimsical tavern
stylized anthropomorphic animals
warm candlelight
deep brown wood
burgundy red
muted brass gold
smoky atmosphere
slightly dangerous but playful
premium indie game art
2.5D painterly stylized illustration
```

整体氛围：

- 夜晚；
- 老旧木质酒馆；
- 暖黄蜡烛光；
- 背景较暗；
- 桌面是视觉中心；
- 有烟雾、酒杯、旧木板、黄铜装饰；
- 危险感存在，但不是恐怖游戏；
- 角色略夸张、可爱、狡猾；
- 不做儿童卡通风；
- 不做写实真人风；
- 不做日系二次元；
- 不做赛博朋克；
- 不做高饱和糖果色。

# 7. 角色统一生成规则

角色共 8 个。

每个角色建议先生成：

1. 标准待机立绘；
2. 怀疑；
3. 撒谎 / 得意；
4. 惊讶；
5. 大笑；
6. 紧张；
7. 淘汰；
8. 胜利。

最终约 64 张。

## 通用角色构图

所有角色：

- 半身或胸像；
- 正面偏 10–15°；
- 坐姿；
- 双臂可见；
- 胸口以上完整；
- 透明背景；
- 不要桌子；
- 不要椅子；
- 不要武器；
- 不要文字；
- 角色头顶和双肩保留边距；
- 光源来自左前方暖色烛光；
- 右侧有轻微冷暗轮廓光；
- 同一角色不同表情必须服装、比例、毛色一致。

# 25. 生图一致性要求

这是非常重要的一部分。

生成不同角色时不要每次只贴单张提示词。

应该给模型同时附加统一描述：

```text
All character images belong to the same game.
Use exactly the same rendering style, lighting direction, camera distance,
line quality, material treatment, color grading, body proportions and tavern atmosphere.

Characters must look like members of one coherent cast,
not images from different artists or different games.

Use:
stylized painterly 2.5D indie game character rendering,
warm amber candlelight from front-left,
subtle cool rim light,
dark burgundy / walnut / antique brass world palette,
clean mobile-readable silhouette,
transparent background.
```

---

# 26. 同一角色表情一致性要求

生成情绪差分时加入：

```text
Keep the exact same character identity as the reference:
same species,
same face shape,
same fur markings,
same eye color,
same clothing,
same accessories,
same body proportions,
same camera angle,
same crop,
same lighting.

Only change:
facial expression,
ear position where applicable,
hand gesture,
minor upper-body pose.

Do not redesign the character.
```

如果生图模型支持参考图或角色一致性功能，必须用待机立绘作为 reference。

# 29. 最重要的生成顺序

推荐严格按下面顺序：

```text
1. BG-01
2. TEX-01
3. CARD-01
4. CHAR-WOLF-01
5. 用狼的画风确定角色统一标准
6. 生成其他 7 个角色待机
7. PROP-01
8. UI-01
9. 放进真实游戏测试
10. 确认风格没有问题
11. 再批量生成全部角色情绪
12. 最后补道具和特效
```

原因：

如果一开始直接生成 100 张，
最后发现整体画风不适合手机游戏，
会导致全部返工。

第一批只需要把：

```text
场景
角色
卡牌
左轮
UI
```

五个视觉系统确定下来。

# 30. 最终风格验收标准

把所有素材摆在一张图里时，应当明显感觉：

> “这是同一个游戏里的东西。”

而不是：

```text
角色像动画
+
桌子像写实照片
+
卡牌像赌场素材
+
按钮像手游商城
+
左轮像军事 FPS
```

统一性优先于单张图片的精细度。

最终视觉应该保持：

```text
暗色酒馆
暖色烛光
深木材质
酒红主色
旧黄铜装饰
半卡通动物
轻危险感
轻幽默感
移动端清晰度
原创游戏身份
```
